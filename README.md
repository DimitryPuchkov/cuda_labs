## Вывод
Время выполнения операций с матрицами на GPU может быть до 500 раз меньше чем на CPU (умножение матриц с использованием разделяемой памяти). Использование разделяемой памяти дает выигрыш по времени 14%. Однако такие результаты возможны при достаточно больших матрицах, так как для выполнения вычислений на GPU требуется потратить время на передачу данных на устройство и обратно.
