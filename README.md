# cuda_lab1
## Задание
Выделить на GPU массив arr из 10^9 элементов типа float и инициализировать его с помощью ядра следующим образом: arr[i] = sin((i%360)*Pi/180). Скопировать массив в память центрального процессора и посчитать ошибку err = sum_i(abs(sin((i%360)*Pi/180) - arr[i]))/10^9. Провести исследование зависимости результата от использования функций: sin, sinf, __sin. Объяснить результат. Проверить результат при использовании массива типа double.

## Вывод
- Функции `sinf` и `__sinf` работают с типом float и в случае передачи double делают каст во float поэтому что на типе float что на типе double ошибка прмерно в 7-9 знаке, а функция sin работает с типом double, а в случае передачи float конвертирует его в double поэтому при рассчетах с помощью этой функции и типа double достигается наименьшая ошибка в 18 знаке.
- Функция sin оказалась наиболее быстрой (на обоих типах данных наименьшее время), хотя теоретически sin должен быть самым долгим, sinf побыстрее, а __sinf самым быстрым. Полагаю такой результат был получен в связи с применяемыми оптимизациями (запускал в visual studio) такими как кеширование результатов в sin (для sinf и __sinf нет такого по умолчанию). Была гипотеза что это происходит из-за явного приведения типов, однако запуск без явного приведения с float и с double не выдал качественно другого результата. Однако в реальных задачах когда нет возможности кешировать результат лучше всего будет использовать __sinf как самую быструю функцию.
